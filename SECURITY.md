# Politica de seguranca - StayGo Landings

Este repositorio pode ser usado como area publica de templates, paginas estaticas e install-kit da StayGoBot.

## Pode ficar publico

- Templates HTML, CSS e JavaScript sem dados reais.
- Exemplos de instalacao do install-kit.
- Textos comerciais, componentes visuais e assets publicos.
- Documentacao para desenvolvedores integrarem formularios e chat da Laura.

## Nunca publicar aqui

- Arquivos `.env` ou qualquer variacao com segredos.
- Chaves de API, tokens do Google, Meta, OpenAI, Evolution, Asaas ou Cloudflare.
- Senhas de VPS, SSH, banco de dados, FTP, painel de hospedagem ou GitHub.
- Backups, dumps SQL, arquivos `.pem`, `.p12`, `id_rsa` ou certificados privados.
- Prints de conversas reais, dados de leads, telefones sensiveis ou documentos de clientes.
- Configuracoes privadas de Nginx, PM2, Docker ou banco de dados.

## Regra operacional

Antes de publicar uma landing de cliente, revise se ela contem apenas dados comerciais que podem aparecer na internet. Qualquer credencial, token, webhook privado ou dado pessoal deve ficar no ambiente seguro da API, nunca neste repositorio.
